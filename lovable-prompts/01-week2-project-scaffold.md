# Prompt 01 — 本番プロジェクト作成 / 6画面の骨格（Week 2 Day 1）

> 目的：本番プロジェクト `DreamStories-JP` を作り、6画面すべての基本レイアウトとルーティングを一気に立ち上げる。
> ⚠️ クレジット節約のため、まとまった指示を1回で出すのがコツ（無駄な再生成を避ける）。

```
子供向けAIパーソナライズ絵本アプリ「DreamStories」日本版を作ります。
Next.js + TypeScript + Tailwind CSS で、以下の6画面と共通レイアウトの基本形を一度に作ってください。
すべて日本語で表示してください。

【共通レイアウト】
- ヘッダー：左にロゴ「DreamStories」（クリックで / へ）、右に「マイページ」リンク
- 全ページ共通のカラーテーマとフォントを Tailwind の theme に設定
- レスポンシブ対応（375px / 768px / 1440px）

【画面とルーティング】
1. / （ランディング）
   - ヒーロー：「あなたのお子さまが主人公の絵本」＋「絵本を作る」ボタン（→ /create）
   - 特徴カード3つ（AIが作る／12ページ／かわいいイラスト）
   - フッター：会社情報・法的リンクのプレースホルダ、© 2026 DreamStories Japan

2. /create （オンボードチャット）
   - チャット吹き出しが縦に並ぶUI、下部固定の入力欄＋送信ボタン
   - 今はダミーの対話（ハードコード応答）でOK。Week5で実APIに差し替える前提

3. /generating （生成中）
   - 中央に円形プログレスバー（今は静的表示でOK）＋ステータステキスト

4. /preview/[id] （プレビュー）
   - 絵本ビューア：上半分イラスト・下半分テキスト、左右の矢印ボタン
   - 下部にページインジケーター、最下部に「この絵本を購入する（5,000円）」ボタン
   - ダミーデータ12ページ（プレースホルダ画像 https://placehold.co/600x400/FFE5A0/333?text=Page+1 ）

5. /mypage （マイページ / マイライブラリ）
   - タイトル「マイライブラリ」、右上に「＋新しい絵本を作る」ボタン
   - 絵本カードのグリッド（PC4列・タブレット2列・スマホ1列）、今はダミーカード数枚
   - 空状態のプレースホルダも用意

6. /login （ログイン）
   - Googleログインボタン、メール認証フォームの見た目のみ（実認証はWeek2後半でSupabase接続）

【画面遷移】
- ランディング「絵本を作る」→ /create
- /create 完了 → /generating → /preview/[id]
- /preview 「購入する」→（後でStripe。今はダミー遷移）
- /mypage カードクリック → /preview/[id]

【デザインガイドライン（厳守）】
- メインカラー：コーラルピンク #FF9AA2
- サブカラー：ソフトブルー #A8D8EA
- アクセント：バターイエロー #FFE5A0
- ベース背景：クリーム #FFF8F0
- テキスト色：#333333
- フォント：Noto Sans JP（絵本本文は M PLUS Rounded 1c）
- ボタン：角丸12px・パディング16px・影は控えめ
- 雰囲気：温かい・優しい・絵本的（日本の子ども向け）

まずは各画面が「表示され、遷移できる」骨格を優先してください。細部の作り込みはWeek3以降で行います。
```
