# Prompt 02 — ランディングページ改善（Lovable追加プロンプト）

対象ファイル：`src/routes/index.tsx`（＋必要に応じて `src/styles.css`）
既存トークン：`--coral #FF9AA2` / `--sky #A8D8EA` / `--butter #FFE5A0` / `--cream #FFF8F0` / `--font-display: M PLUS Rounded 1c`
既存クラス：`.btn-primary` `.btn-secondary` `.btn-ghost` `.card-soft`

> 使い方：まず【メインプロンプト】を1回投入 → 結果を見て、気になる箇所だけ【個別プロンプト】で微調整。
> クレジット節約のため、いきなり個別を連打せず、まずメインでまとめて変更するのが◎。

---

## 🅰 メインプロンプト（まず1回でこれを投入）

```
ランディングページ（src/routes/index.tsx）を改善してください。既存のデザイントークンとユーティリティクラスをそのまま使い、新しい色は追加しないでください。温かみ・優しさ・子供向けのトーンを保ち、過度に派手にはしないでください。

【厳守する制約】
- 色は既存トークンのみ：--coral(#FF9AA2) / --sky(#A8D8EA) / --butter(#FFE5A0) / --cream(#FFF8F0) / --muted-foreground(#7A6E63)
- 見出しは font-display（M PLUS Rounded 1c）
- ボタンは既存の .btn-primary / .btn-secondary / .btn-ghost を活用
- ヘッダー(Header.tsx)・フッター(Footer.tsx)・FAQ・サンプルギャラリーの構造は変更しない
- レスポンシブを維持（375px / 768px / 1440px で崩れない）

【1. ヒーローの改善】
- 2カラム構成にする：デスクトップ(md以上)は左テキスト・右ビジュアル、モバイルはテキストの下にビジュアル
- 右ビジュアルとして「開いた絵本」のカードを置く：白背景・角丸2xl・柔らかい影(--shadow-soft)、左ページに大きな絵文字イラスト(🚀)、右ページに手書き風の1行「たろうくんの ぼうけん」（font-display）。カードは少しだけ傾け(rotate -2deg)、周囲に星⭐とハート💗の小さな装飾を control された数だけ浮かべる（3〜4個、opacity低め）
- 既存のぼかし円(blob)は残すが opacity を少し下げて、絵本カードが主役になるようにする
- 見出しの上のバッジに信頼感の一言を追加：「🌸 3〜8歳向け・世界にひとつの絵本」
- サブコピーの下に小さな安心材料を1行：「入力は3分・生成されるまで料金はかかりません」

【2. CTAボタンを主役にする】
- ヒーローのボタンは「絵本を作る →」を主役の1つに絞る。.btn-primary をサイズアップ（padding大きめ・文字は text-lg）
- 「サンプルを見る」は横並びのボタンをやめ、主ボタンの下に控えめなテキストリンク（下線＋--muted-foreground）にする
- 主ボタンの直下に小さなマイクロコピー：「🎁 クレジットカード不要でお試し」
- 主ボタンに hover 時だけ ふわっと浮く演出（translateY -2px, 0.15s）。常時アニメーションはしない（派手にしない）

【3. 特徴カード(features)を魅力的に】
- 3枚のカードにそれぞれ違うテーマ色を薄く敷く：1枚目=coral 8%、2枚目=sky 12%、3枚目=butter 20% の背景ティント（card-soft をベースに背景だけ変える）
- アイコンは h-14 w-14 の丸バッジにして、カードのテーマ色を少し濃くした背景に。絵文字は text-3xl に拡大
- 各カードに hover でわずかに浮く効果（translateY -4px）と、テーマ色の細いボーダー
- カードの高さを揃える（中身が短くても縦位置が揃うように）
- タイトルは font-display、説明は text-sm / --muted-foreground のまま

【4. スマホ最適化】
- ヒーローの上下余白をモバイルで圧縮（pt-10 pb-12 相当）、見出しはモバイルで text-3xl
- 主CTAボタンはモバイルで幅いっぱい（w-full）、高さ56px以上のタップ領域
- 特徴カードはモバイルで1カラム・適度な余白、絵本カードのビジュアルは横幅に対して最大幅を制限して中央寄せ
- 画面全体で横スクロールが出ないこと（ぼかし円がはみ出す場合は overflow-hidden で抑える）
- モバイルでのみ、画面下部に固定の「絵本を作る」バー（sticky bottom, 白背景に影、safe-area 考慮）を追加。デスクトップでは非表示
```

## 🅱 個別プロンプト（メイン投入後、微調整したい時だけ）

### B-1. ヒーローのビジュアルだけ差し替え
```
ヒーロー右側の「開いた絵本」カードのデザインだけ調整してください。他は変更しないでください。
- 絵本カードの中を見開き2ページ風に：左ページ上部にイラスト絵文字、下部に短い物語テキスト
- ページの間に本の綴じ目（中央に薄い縦グラデーションの影）
- カード全体を rotate -2deg、hover でまっすぐ(0deg)に戻る 0.3s の演出
- 装飾の星・ハートは4個まで、opacity 0.5 以下で控えめに
既存の色トークンのみ使用、派手にしない。
```

### B-2. ボタンの押し心地
```
「絵本を作る」ボタン(.btn-primary)の押し心地だけ改善してください。他は変更しないでください。
- hover: translateY(-2px) と影を少し強く（0.15s ease）
- active: translateY(0)
- フォーカスリング：--coral のリングを見えるように（アクセシビリティ）
- 常時点滅・常時アニメーションはしない
```

### B-3. 特徴カードの色分けを微調整
```
特徴カード3枚の背景ティントの濃さだけ調整してください。うるさく感じないよう、各色 5〜12% の薄さに。
1枚目 coral、2枚目 sky、3枚目 butter。文字とのコントラストは AA を確保（テキストは #333333 のまま読みやすく）。
```
