# Prompt 05 — Supabase 認証接続（Week 2 Day 4）

> 目的：ログイン機能を接続する。柴崎さんから **Supabase URL** と **Anon Key** を受け取ってから実施。
> 受け渡し：岩田→認証画面の仕様 / 柴崎→URL・Anon Key・認証設定（資料 第16章）

```
このアプリにSupabase認証を接続してください。
Supabase URL: [柴崎さんから受け取った値を貼る]
Supabase Anon Key: [柴崎さんから受け取った値を貼る]

【実装する機能】
- Googleログイン
- メール認証（サインアップ／ログイン）
- ログアウト
- 未ログイン状態で /mypage にアクセスしたら /login へリダイレクト
- ログイン状態はヘッダーに反映（ログイン中はマイページ、未ログインはログインリンク）

【デザイン】
- ログイン画面は温かみのある絵本的トーン
- メインカラー：コーラルピンク #FF9AA2 / ベース背景：クリーム #FFF8F0
- フォント：Noto Sans JP
- すべて日本語表示
```

## ⚠️ 注意
- Anon Key は「公開してよい鍵」だが、**Dify APIキーや秘密鍵は絶対フロントに書かない**（Week5でEdge Function経由にする理由）。
- 接続エラーが出たら：Supabase Dashboard で値を再確認 → 柴崎さんに確認（資料 第17章）。
