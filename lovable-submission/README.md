# Lovableに提出するデザイン/アニメーション一式

このフォルダには、これまでに作ったUIデザインとアニメーションの実体だけが入っています。
プレビュー用の仕組み・ツール（`*.mjs`、`wireframes/` など）は含めていません。

## 中身（6ファイル）
| ファイル | 内容 |
|---|---|
| `src/styles.css` | 全アニメーションの `@keyframes`（ヒーローの縦スクロール `ds-vup/ds-vdown`、浮遊 `ds-float`、背景 `ds-blob`、マーキー `ds-marquee`、スクロール表示 `.reveal`、チャットの `ds-dot` など）とデザイントークン |
| `src/routes/index.tsx` | ランディング（中央見出し＋両脇の絵本カバーが↓↑↓↑スクロール、立ち上がり演出、特徴/ステップ/サンプル/FAQ/CTA、フッター） |
| `src/routes/create.tsx` | オンボードチャット（吹き出し・タイピング演出・進捗・テーマ選択） |
| `src/routes/preview.$id.tsx` | 絵本プレビュー（本物のように3Dでめくれるアニメ・固定サイズ） |
| `src/components/Header.tsx` | ヘッダー（スマホ折り返し修正済み） |
| `src/components/Footer.tsx` | 4カラムフッター |

## Lovableへの反映のしかた（2通り）

### 方法A：Lovableのコードエディタに貼り付け（手軽・おすすめ）
1. Lovableでプロジェクトを開く → 右上の **`</>` (Code / Dev Mode)**
2. 上の各ファイルを、Lovable側の同じパスのファイルで開く
3. **全選択 → 貼り付け**（このフォルダの中身で置き換え）
4. 6ファイル分くり返す → プレビューで反映を確認

### 方法B：GitHub連携（Week 8のやり方）
LovableをGitHubに連携している場合は、連携ブランチにこの6ファイルを置いてpushすると自動で同期されます。

## 注意
- Reactの仕様上、「デザインだけ」を部品から切り離すことはできません。各コンポーネントは
  **見た目＋最小限の描画ロジック**が一体です（画面遷移やstateはそのUIを動かすのに必要な分だけ）。
  除外したのは、あくまで**プレビュー生成やローカル起動のための外部ツール**です。
- `src/styles.css` を最初に反映すると、アニメーションのkeyframesが揃って他画面も正しく動きます。
